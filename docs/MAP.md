# Map: Meridian Relay Station

An original multi-room facility built for Assailward 2D. Layout data: `src/sim/maps/compoundLayout.ts`, generated by `scripts/genmap.py` (`python3 scripts/genmap.py` prints it). Metadata — rooms, cameras, spawns, anchors, routes — is in `src/sim/maps/compound.ts`. The map is validated by `tests/map.test.ts`.

* 100 × 70 cells, 16 px per cell (1600 × 1120 px). An operator is 18 px wide; a doorway is 48 px.
* The building covers cells 14–86 × 12–58. It holds nine rooms in a 3 × 3 arrangement around the **Server Room** objective, surrounded by four yards.

## Legend

| Char | Meaning |
| --- | --- |
| `#` | Concrete wall (indestructible) |
| `=` | Soft wall: destructible per cell; defenders can reinforce it (panels of up to 4 cells) |
| `%` | Pre-reinforced wall: only a hard-breach charge opens it |
| `+` | Prop / cover (indestructible, blocks movement, bullets and sight) |
| `D` | **Doorway**: a permanent open passage, 3 cells wide, that defenders can barricade (no doors) |
| `o` | Objective zone (plant area) |
| `.` | Interior floor |
| `,` | Exterior ground |

## Approaches to the Server Room

| Side | Entry | Needs |
| --- | --- | --- |
| North | doorway from the Main Hall | open, or breach its barricade |
| North | soft wall from the Main Hall (7 cells) | soft breach, hammer or explosives |
| East | doorway from the Break Room | open, or breach its barricade |
| East | two soft wall sections from the Break Room | soft breach, hammer or explosives |
| South | doorway from the Archive | open, or breach its barricade |
| South | pre-reinforced wall from the Archive (19 cells) | **hard-breach charge** |
| West | two soft wall sections from Storage | soft breach, hammer or explosives |

Exterior entrances:
* Doorways into the Lobby (N, W), Main Hall (N), Offices (E), Garage (W, S) and Workshop (S, E).
* Soft exterior walls on the Offices (N), Storage (W), Break Room (E) and Archive (S).

## Spawns and AI routes

* **Attacker spawns:** North Gate, West Lot, Southeast Dock. During preparation attackers are confined to their spawn rectangle. Cover blocks the direct sightline from the Main Hall doorway to the North Gate spawn.
* **Defender spawn:** inside the Server Room.
* **AI approach routes** (`approaches`): North, Lobby, Garage, East and South. South is flagged `hardBreach`: the attacker carrying the hard-breach charge takes it to the reinforced wall.
* **Defender anchors:** five positions inside the Server Room. **Roam points:** eight room centres. **Prep spots** for roamers are kept out of the attackers' spawn sightlines.

## Cameras

Map cameras: Lobby, Main Hall, Break Room, Garage, Workshop and North Yard (exterior).
